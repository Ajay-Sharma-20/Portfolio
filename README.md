# 🚀 Full-Stack & DevOps Portfolio

A modern, responsive, and performance-optimized personal portfolio designed to showcase my projects, technical skill set, and software engineering journey. Built with React, Tailwind CSS, and optimized for seamless user experience across all devices.

---

## 🛠️ Tech Stack

**Frontend & Styling**
* **Core:** React.js, JavaScript (ES6+)
* **Styling:** Tailwind CSS, Framer Motion (Animations)
* **Icons & Assets:** Lucide React / React Icons

**Hosting & Deployment**
* **Platform:**  Netlify

---

## ✨ Features

* 📱 **Fully Responsive:** Seamless layout adaptation for mobile, tablet, and desktop viewports.
* ⚡ **High Performance:** Lightweight build with optimized asset loading and fast page speed.
* 🎨 **Modern UI/UX:** Clean aesthetics, subtle micro-interactions, and smooth scrolling.
* 📁 **Showcase Sections:** Integrated sections for **About Me**, **Featured Projects**, **Tech Stack**, and **Contact**.

---

## 📂 Featured Projects Included

1. **Smart Career Guidance System**
   * *Stack:* React.js, Python (Flask), Machine Learning
   * *Description:* AI-driven platform generating dynamic, personalized learning pathways and career roadmaps based on user skill gaps.

2. **ChapterZero — Library Management System**
   * *Stack:* MongoDB, Express.js, React.js, Node.js (MERN), Cloudinary API
   * *Description:* Full-stack web application featuring separate admin and user panels, book management, and Cloudinary media uploads.

3. **TubeMark — Chrome Extension**
   * *Stack:* JavaScript, HTML5, CSS3, Chrome Extension API
   * *Description:* Productivity tool allowing users to bookmark specific YouTube video timestamps alongside custom notes.

4. **Smart Intruder Detection System**
